# Internationalization Guide

## Languages
- English (default)
- French

## Rules
- All text must be translatable
- Use JSON files:
  - en.json
  - fr.json

## Example
{
  "home": {
    "title": "Empowering Youth for a Better Future"
  }
}

## Language Switch
- Add toggle in navbar
- Store language preference

## Do Not
- Hardcode any text in components
