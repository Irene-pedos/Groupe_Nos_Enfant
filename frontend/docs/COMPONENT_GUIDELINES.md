# Component Rules

## General
- Components must be reusable
- Use props properly
- Avoid duplication

## Naming
- Use clear names:
  - HeroSection
  - ProgramCard
  - StoryCard
  - CTASection

## Structure
Each component must:
- Be isolated
- Be clean and readable
- Accept dynamic data

## Example Components
- Navbar
- Footer
- Hero Section
- Program Cards Grid
- Testimonials Section
- Donation CTA
