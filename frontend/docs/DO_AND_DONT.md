# DO and DON'T Rules

## ✅ DO
- Use clean and modern layouts
- Use consistent spacing
- Focus on readability
- Use real-world storytelling tone
- Keep navigation simple
- Use reusable components
- Make UI mobile-first
- Use meaningful icons
- Use proper loading states

## ❌ DON'T
- Do not overcrowd the UI
- Do not use too many colors
- Do not hardcode text (use translations)
- Do not use inconsistent spacing
- Do not create complex animations
- Do not break accessibility rules
- Do not mix different design styles
- Do not use generic placeholder text
