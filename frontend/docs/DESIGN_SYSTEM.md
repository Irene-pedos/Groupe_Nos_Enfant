# Design System — NGO Style

## Design Tone
- Warm
- Human
- Trustworthy
- Inspiring

## Colors
- Primary: Deep Blue (trust)
- Secondary: Warm Orange (hope/action)
- Neutral: White, Light Gray

## Typography
- Headings: Bold, clean, modern
- Body: Simple, readable

## Layout
- Clean spacing
- Large sections
- Clear hierarchy

## Components to Use (shadcn)
- Button
- Card
- Badge
- Dialog
- Input
- Textarea
- Tabs
- Accordion
- Navigation Menu

## UI Patterns
- Cards for programs and stories
- Sections with strong headings
- Image + text combinations
- CTA sections

## Accessibility
- High contrast text
- Clear navigation
- Large clickable areas
