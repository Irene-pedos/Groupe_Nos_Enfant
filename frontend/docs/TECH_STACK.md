# Tech Stack Instructions

## Framework
- Next.js (App Router)
- TypeScript (strict mode)

## UI System
- shadcn/ui components
- Tailwind CSS

## State & Data
- React hooks
- Server Components when possible

## Internationalization
- Support English and French
- Use structured translation files (JSON)
- No hardcoded text

## Folder Structure
/app
  /(public)
  /(admin)
  /components
  /lib
  /hooks
  /translations

## Styling Rules
- Use Tailwind utility classes
- Avoid inline styles
- Maintain consistent spacing and typography

## Performance
- Optimize images
- Use lazy loading
- Avoid unnecessary re-renders
