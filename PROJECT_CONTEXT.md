# Project Context — Groupe Nos Enfants (GNE)

## Overview
This project is a modern web application for an NGO called Groupe Nos Enfants (GNE), based in Rwanda.

The platform must:
- Present the NGO’s mission, programs, and impact
- Allow users to donate, volunteer, or apply for support
- Build trust with donors and partners
- Inspire action through storytelling and real impact

## Core Focus
The organization supports:
- Young mothers
- Vulnerable children and youth
- Education access
- Youth empowerment and entrepreneurship

## Vision
A society where every child and young person is protected, empowered, and able to become a responsible and self-reliant citizen.

## Mission
To unlock human potential of children and youth through inclusive, practical, and scalable solutions combining education, skills, and entrepreneurship.

## Key Principles
- Human-centered design
- Trust and transparency
- Emotional storytelling
- Accessibility for all users
- Simplicity over complexity

## Target Users
- Beneficiaries (young mothers, youth)
- Donors and sponsors
- Volunteers
- Partners
- General public
