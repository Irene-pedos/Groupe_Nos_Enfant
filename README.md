# Groupe_Nos_Enfant
Groupe Nos Enfants (GNE) is part of this movement. It was founded in September 1999 in Butare (now Huye), then the country’s main academic hub, through the initiative of Father Modeste Mungwarareba and Mr. Laurien Ntezimana—intellectuals engaged in peacebuilding and reconciliation in Rwanda—together with their Swiss partner, Ms. Antoinette Bruttin.
